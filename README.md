## 앱 소개

앞으로의 50년은 어떤 계절일까. 25개 문항에 답하면 정해진 규칙에 따라 지금의 계절과 유형을 정리해 보여주고, 매일 한 문장을 건네는 앱입니다.

**개인정보를 수집하지 않습니다.** 회원가입도 로그인도 없으며, 진단 결과와 보관한 문장은 사용자의 기기 안에만 저장됩니다.

## 파일 구성

HTML 은 마크다운 원문에서 생성합니다. 두 벌을 손으로 관리하면 어긋나므로 원문을 먼저 고치고 다시 생성합니다.
